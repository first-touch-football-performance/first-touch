FIRST TOUCH – Website

1. Öffne index.html im Browser, um die Website anzusehen.
2. Ersetze DEINE-EMAIL@BEISPIEL.AT in index.html durch deine Kontaktadresse.
3. Prüfe Qualifikationen, ergänze Impressum und Datenschutzhinweise.
4. Lege auf github.com ein öffentliches Repository namens first-touch an.
5. Lade index.html in das Repository hoch.
6. Unter Settings > Pages: Deploy from a branch > main > /(root) auswählen und speichern.
7. Nach der Veröffentlichung ist die Seite unter https://DEIN-BENUTZERNAME.github.io/first-touch/ erreichbar.

Hinweis: Die Seite verwendet bewusst keine externen Fotos oder Tracking-Dienste.
